# Логика решения

Задание: скрипт на FastAPI принимает PDF с сайта госзакупок и через API модели возвращает сумму контракта, сроки, ключевые требования к исполнителю и список штрафов.

Задача выглядит как «отдать текст модели и вернуть ответ». Ломается она не там. Ниже то, что я закладывал, и почему.

## Алгоритм

```
PDF -> хеш файла -> кеш -> текст -> проверка на скан -> гашение инструкций
    -> модель -> JSON -> схема -> ответ + расход
```

1. **Хеш файла.** SHA-256 от байтов, ответ по этому ключу лежит в кеше. Один и тот же документ присылают по несколько раз, а каждый разбор стоит денег.
2. **Извлечение текста.** `pypdf` постранично, с ограничением по числу знаков. Документация закупки бывает на сотни страниц, и целиком она стоит дороже, чем даёт пользы. Обрезка не молчаливая: в ответе стоит `truncated: true` и предупреждение.
3. **Проверка на скан.** Если на страницу приходится меньше 120 знаков, это картинка без текстового слоя. Сервис возвращает 422 и говорит, что нужен OCR. Без этой проверки модель получит пустую строку и напишет правдоподобную выжимку, которой нет в документе.
4. **Гашение инструкций.** Документ присылает посторонний. Строка вида «игнорируй предыдущие инструкции» внутри PDF для модели выглядит так же, как указание от сервиса. Такие места заменяются заглушкой, а факт попадает в `warnings`.
5. **Вызов модели.** Один запрос, `temperature: 0`, `response_format: json_object`. Адрес API вынесен в переменную окружения, поэтому подходит OpenAI, российский шлюз или локальная модель через Ollama.
6. **Разбор ответа.** JSON вынимается даже из обёртки в тройные кавычки и из текста вокруг. Дальше валидация в схему Pydantic.
7. **Ответ.** Кроме выжимки возвращаются число страниц, признак обрезки, признак кеша, имя модели и расход токенов со стоимостью в рублях.

## Что здесь неочевидно

**Деньги в русских документах не парсятся как число.** В «1 250 000,50 руб.» пробел работает разделителем разрядов (иногда неразрывный), запятая как дробная часть и хвост из букв. `Decimal(raw)` на такой строке падает. Плюс модель может вернуть «2,5 млн рублей». Поэтому суммы проходят через отдельный разбор с множителями тыс/млн/млрд, и хранятся в `Decimal`, а не во `float`: на деньгах float даёт расхождение в копейках.

**Даты приходят в трёх видах.** `01.03.2026`, `2026-03-01` и «1 марта 2026 г.». Все три встречаются в извещениях, разбор поддерживает каждый.

**Модель возвращает не то, что обещает.** Требования иногда приезжают одной строкой с переносами вместо списка, сумма строкой вместо числа, штраф без суммы, но с формулой. Схема приводит это к одному виду, а не падает.

**Пустое поле лучше выдуманного.** В промпте прямо сказано: не додумывать, ставить null и писать причину в `warnings`. Для тендера цена ошибки высокая: неверная сумма контракта в выжимке хуже, чем её отсутствие.

**Стоимость видна в ответе.** Расход токенов и цена в рублях возвращаются с каждым разбором. Без этого понять, во что обходится сервис, можно только в конце месяца по счёту.

## Что закрыто со стороны безопасности

Сервис принимает файл от постороннего и на каждый запрос тратит деньги, поэтому отдельно закрыты четыре вещи.

**Размер и объём.** Файл читается порциями по мегабайту и обрывается на первом байте сверх лимита, иначе присланные гигабайты занимали бы память до того, как получат отказ. Отдельно стоит предел на число страниц: PDF из десятков тысяч пустых страниц весит мегабайт, лимит по знакам на нём не срабатывает никогда, и один такой файл занимает процесс надолго.

**Инструкции внутри документа.** Строки вида «игнорируй предыдущие инструкции» гасятся до отправки, факт уходит в предупреждения ответа. Фильтр по образцам, то есть он ловит известные формы, а не все возможные.

**Тело ответа провайдера не уходит клиенту.** В ошибках внешнего API встречаются идентификаторы организации и детали тарифа, поэтому наружу идёт код и общая фраза, а подробности пишутся в лог сервиса.

**Доступ и частота.** Ключ в заголовке `X-API-Key` включается переменной окружения, по умолчанию доступ открыт, чтобы сервис можно было запустить и посмотреть. Ключи сравниваются в байтах: `hmac.compare_digest` на строках с не-ASCII кидает исключение, и сервис отвечал бы пятисоткой вместо отказа в доступе. Рядом ограничение частоты по адресу, потому что без него открытый эндпоинт оплачивает владелец сервиса.

## Чего в решении нет

- OCR для сканов. Сервис их распознаёт как сканы и честно отказывает, а не выдумывает выжимку. Подключение Tesseract или облачного OCR это следующий шаг, отдельный по стоимости.
- Разбиение длинного документа на куски с последующей сборкой. Сейчас берётся начало документа, где в извещениях и лежат цена и сроки. Для многотомной документации нужен проход по кускам с объединением, это дороже в разы.
- Кеш в памяти процесса. Для одного инстанса достаточно, при нескольких воркерах нужен общий Redis.

## Тесты

27 штук, `python -m pytest tests/ -q`. Проверяются разбор денег и дат в русских формулировках, извлечение текста и обрезка, отказ на битом файле, распознавание скана, гашение инструкции в теле документа, разбор JSON из обёртки и то, что повторный запрос тем же файлом не идёт в модель.

PDF для тестов собирается прямо в коде теста минимальными объектами, чтобы не тащить в зависимости генератор документов ради проверки.
